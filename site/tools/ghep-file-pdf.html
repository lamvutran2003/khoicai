Kết quả

    Cách dùng

    1. Bấm vào khung trên để chọn file, hoặc kéo thả các file PDF vào. Có thể chọn thêm nhiều lần.
    2. Dùng nút ↑ ↓ để đổi thứ tự; file ở trên cùng sẽ nằm đầu tiên.
    3. Bấm Ghép PDF, file mới được tải về máy ngay.

    Hỏi đáp

    File của tôi có bị gửi lên mạng không?

    Không. Việc ghép file chạy hoàn toàn trên trình duyệt của bạn, kể cả khi bạn tắt mạng sau khi mở trang. Phù hợp với hợp đồng, hồ sơ, giấy tờ cá nhân cần giữ kín.

    Có giới hạn số file hay dung lượng không?

    Không giới hạn số lần. Dung lượng tùy bộ nhớ máy bạn; máy tính thường ghép được vài trăm MB, điện thoại nên ghép dưới khoảng 100 MB mỗi lần.

    File PDF có mật khẩu thì sao?

    File đang đặt mật khẩu mở hoặc khoá chỉnh sửa cần được mở khoá trước. Bạn có thể mở file bằng trình đọc PDF, chọn In và lưu lại thành PDF mới rồi ghép.
