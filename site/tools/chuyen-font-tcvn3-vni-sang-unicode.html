Bảng mã nguồn

Vì sao chữ bị lỗi font?

Trước khi Unicode phổ biến, văn bản tiếng Việt được gõ bằng các bảng mã riêng như TCVN3 (ABC) với font .VnTime, .VnArial và VNI-Windows với font VNI-Times. Mỗi bảng mã "mượn" các ký tự Latin để vẽ chữ có dấu, nên khi văn bản rời khỏi đúng font đó (dán vào email, Zalo, Google Docs, hoặc mở trên máy không có font), chữ hiện thành ký tự lạ:

Công cụ trên đổi các ký tự đó về chữ tiếng Việt Unicode, loại chữ mọi máy tính, điện thoại và trang web đều hiển thị đúng.

Cách dùng

  1. Với một đoạn chữ: mở file cũ, sao chép đoạn chữ (dù đang hiện đúng trong Word), dán vào ô trên. Kết quả hiện ngay; bấm Sao chép.
  2. Với cả file Word .docx: thả file vào khung "Chuyển cả file Word", rồi tải file mới về. Chỉ những đoạn dùng font cũ mới bị đổi, nên văn bản lẫn cả chữ Unicode lẫn chữ font cũ vẫn ra đúng.
  3. File .doc đời cũ: mở bằng Word, chọn Lưu thành (Save As) định dạng .docx, rồi thả file .docx vào đây.

Câu hỏi thường gặp

Có cần cài Unikey hay UniKey Toolkit không?

Không. Cách cũ là mở Unikey, chọn bảng mã nguồn/đích trong Toolkit rồi chuyển qua clipboard; trang này làm việc đó ngay trên trình duyệt, kể cả trên điện thoại và máy Mac, và tự đoán bảng mã giúp bạn.

File của tôi có bị tải lên mạng không?

Không. Văn bản và file Word được xử lý ngay trong trình duyệt trên máy bạn; trang không gửi nội dung đi đâu. Bạn có thể tắt mạng sau khi mở trang và công cụ vẫn chạy.

Kết quả toàn chữ IN HOA bị sai thành chữ thường?

Font .VnTimeH, .VnArialH (có chữ H ở cuối) dùng mã chữ thường nhưng hiển thị thành chữ hoa. Đánh dấu ô "Font chữ hoa" để ra chữ in hoa. Với file Word, công cụ tự nhận font đuôi H.

Tự nhận bảng mã đoán sai thì sao?

Chọn bảng mã bằng tay trong ô "Bảng mã nguồn". Đoạn càng dài thì đoán càng chắc; với vài chữ ngắn, hãy thử cả TCVN3 và VNI xem cái nào ra chữ đúng.
