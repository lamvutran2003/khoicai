Dùng dấu gạch cho khoảng trang, dấu phẩy để ngăn cách. "8-" là từ trang 8 đến hết.
1 = tách từng trang ra file riêng (tải về dạng .zip)

Kết quả

Cách dùng

  • Lấy trang: nhập các trang cần giữ, ví dụ 1-3, 7, để được file mới chỉ có các trang đó. Viết 5-1 để đảo ngược thứ tự.
  • Xoá trang: nhập các trang muốn bỏ, ví dụ trang trắng hay trang bìa.
  • Chia file: file 30 trang chia mỗi file 10 trang sẽ ra 3 file, tải về trong một file nén .zip.

Hỏi đáp

Tách file có làm giảm chất lượng không?

Không. Các trang được sao chép nguyên vẹn, giữ chữ, hình và độ nét như file gốc.

File của tôi có bị gửi lên mạng không?

Không. Mọi xử lý diễn ra trên trình duyệt của bạn; trang web không nhận được nội dung file.
